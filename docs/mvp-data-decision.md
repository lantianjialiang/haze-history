# MVP 数据组合阶段评审

**当前实现：** 默认 PM 源是监测总站历史归档（`quotsoft-cnemc`）：全国城市自 2014-05-13，北京自 2013-12-06。CAMS 只作模型对照。气象历史仍未接入。下文保留 A0.6 阶段的候选评审记录；原始探测见[数据源实测](data-source-report.md)和[许可](licenses.md)。

建议先以 CAMS 为趋势源，并将北京使馆档案限制在实测对照用途。北京的 208 个匹配样本日显示 CAMS 平均高出 32.84 μg/m³。35 和 75 两个阈值的超标天数分别多 98 天和 53 天，生产界面应保留模型标识。

40 城 CAMS 试跑用时约 3.34 分钟，200 个年度请求失败 3 个。单日增量用时约 0.65 分钟，40 个请求全部成功。生产方案拟以城市和年度划分缓存任务，每源独立限流，按日增量更新，并保留失败城市和年度用于重试。当前计时仅涵盖 CAMS。

评审需要决定可接受的历史缺测范围、NOAA 站点选择与最低有效小时数，以及第二个真实 PM2.5 源可接受的城市覆盖范围。缺测继续用 null；遇下载失败保留不可用或重试状态。
