# 设计系统

界面使用深绿查询区和浅灰绿工作区。应用主题切换后，表面、文字、图表和缺测样式同步更新。设计 token 定义在 web/src/style.css，图表调色板定义在 web/src/charts.ts。

| 角色 | 浅色 | 深色 |
|---|---|---|
| 页面背景 | #f4f5f0 | #101a15 |
| 卡片 | #ffffff | #1a2822 |
| 正文 | #192e25 | #e5ede5 |
| 辅助正文 | #51675c | #adc1b4 |
| PM2.5/AQI | #286d59 | #79b9a4 |
| 气象口径 | #b27031 | #f4bc78 |

缺测使用灰色斜纹，年度柱图保留独立缺测标记。数据不足使用较浅柱色和斜纹。月度色阶由浅至深表示天数。图表下方可展开数据表。

桌面 ≥1200 px。平板 768–1199 px 保留侧栏。手机 <768 px 将筛选移至图表上方；窄日历改为纵向。字号、间距、圆角、边框和阴影在 CSS 中集中维护。

运行 Playwright 的 layout.spec.ts 可在 test-results 生成桌面 1440 px 和手机 390 px 的浅色及深色截图。
