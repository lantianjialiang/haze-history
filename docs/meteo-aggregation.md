# 气象观测聚合研究

[实测报告](data-source-report.md)列出六个候选站点及每年的有效日。当前使用预选站点评估可行性，距离是城市中心与候选坐标的球面距离。生产方案拟按 ISD 站点目录筛选覆盖目标时段的站点，在 25 km 内先比较同时满足能见度和湿度的日覆盖，再以距离和站点 ID 打破平局。需实测校验距离阈值和机场站代表性。跨年换站应保留站点说明，避免将多站混为同一条记录。

探测使用 [NOAA 固定宽度档案说明](https://www.ncei.noaa.gov/pub/data/noaa/ISH-DVD2012/ish-tech-report.pdf)。能见度原始字段是米，999999 为缺测。温度和露点按 0.1 °C 缩放，9999 为缺测。探测接受质量码 0、1、4、5、9，拒绝其他标记。相对湿度由气温和露点通过 Magnus 形式计算，上限保留 100%。小时标签转换为 Asia/Shanghai，跨 UTC 年边界读取相邻档案。每个本地小时的同一指标最多参与一次计数。

基线按两个指标同时可用的小时做采样覆盖比较，矩阵含 1、8、18 小时门槛。生产日均可按配对观测的全天算术平均生成，须在 A0.6 确认有效小时数。低频站点按 18 小时筛选几乎全空。8 小时门槛可增加部分城市的有效日，样本的昼夜代表性仍需分析，门槛下调不代表同等置信度。

[NOAA GHCNh](https://www.ncei.noaa.gov/products/global-historical-climatology-network-hourly)已替代 ISD。重新匹配当前站点时，应使用 GHCNh 目录的站名、地理坐标和数据起止时间，直接检查能见度和湿度字段的覆盖率，再判断是否可与旧 ISD 序列拼接。
